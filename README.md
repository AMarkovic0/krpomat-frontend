# Krpomat Frontend

This is a web app to display and analyze data obtained from all the Krpomat machines owned by logged user.

# Versions

To checkout correct version, please use git tags:

- beta\_vX.X -> Beta version X.X
- prod\_vX.X -> Production version X.X

>**NOTE:** Each tagged version has correspondent tag in the [backend repository](https://github.com/AMarkovic0/krpomat-web). Please use adequate versions of frontend AND backend app.

# Run

To run a production build, please install serve and enter:

```
npm run build
serve -sn build
```

To run development build please enter:

```
npm start
```
